操作说明（用户手册）

适用版本：v1.0 ｜ 适用对象：日常用它做表格检索、台账转换、数据核对的业务人员配套文件：README、EXE 打包说明、验收报告

一、启动与关闭

方式 A：EXE 绿色版（推荐）

  1. 把 表格工具_v1.0_win64.zip 解压到可写目录（如 D:\工具\表格工具，别放 C:\Program Files）。
  2. 双击 **表格工具.exe**。程序窗口显示"正在启动服务…"，2–5 秒后自动用默认浏览器打开界面。
  3. 以后要停止：关闭「表格工具」窗口（服务随之停止）。想再用，再双击一次。

窗口上三个按钮：打开界面（重新开浏览器）、打开数据目录（生成物/备份都在这）、停止并退出。

方式 B：源码运行（改代码或没打包时）

双击 启动.bat，或命令行 python -m app.server --port 8765。

首次使用三步

  1. 在顶部输入框填入表格所在文件夹，或点 浏览… 选目录（会递归扫描子文件夹）；
  2. 点 切换 → 再点 重建索引（首次约 20 秒，66 个表格/25 万单元格实测 18.8 秒）；
  3. 切到「检索」页，输入关键词回车即可。

区域 说明
顶栏左 工作区路径输入框 + 浏览…（系统文件夹选择框）+ 切换 + 重建索引 + 索引状态（已索引的文件数/单元格数）

地址栏带 #search 这类锚点，刷新后仍停留在当前页；检索页还支持 #search?q=合同 这样的深链，可以把一次查询的链接发给同事。

三、检索页：找数、定位、修改

1. 搜索

写法 含义 示例
合同 单关键词，模糊匹配（子串） 命中所有含"合同"的单元格
示例 设计 多个关键词，同一行内都要出现（AND） 项目名含"示例"且同一行有"设计"
示例 OR 乙 切换下拉为「任一关键词（OR）」 含任意一个词的行
"设计合同" 英文双引号包起来 = 短语精确匹配 连续出现"设计合同"
下拉「全部文件」 可只搜某个文件；旁边还可按字段过滤 —

按 回车 或点「搜索」。搜索框为空时不会返回全部数据（避免误触）。

2. 看懂结果

每条结果固定给出 6 个定位信息：文件地址 ｜ 工作表 ｜ 第几行 ｜ 第几列（字母 + 序号）｜ A1 引用 ｜ 字段名，命中内容高亮。

例：第4行 · 第AF列(第32列) · AF4，就是 Excel 里第 4 行、AF 列那个格子。

操作 作用
打开所在文件夹 在资源管理器里定位该文件（文件会被选中）
用 WPS 打开 用系统默认表格软件打开该文件
复制路径 复制完整文件路径到剪贴板
编辑 打开单元格弹窗，看当前值/类型/公式，改完「保存并写回」
底部分页 每页 50 条，可上一页/下一页/输入页码跳转
导出结果 把当前检索结果导成 xlsx（含文件地址/行/列/A1 四列）

3. 修改单元格（写回）

  1. 点结果行右侧「编辑」→ 弹窗显示坐标、当前值、单元格类型、是否合并区；
  2. 选择「修改类型」（文本/数值），填「新值」→ 保存并写回；
  3. 保存成功后该行会标记为已修改；文件被 WPS 打开等外部改动会导致保存被拒（提示冲突），刷新重试即可。

写回规则：

  • 写前自动备份到 data/backup/时间戳/，可还原；
  • 合并单元格只能改左上角，改其它位置会提示"合并区，请编辑左上角单元格"；
  • 公式格可选改「公式」或只改「显示值」；
  • .xls / .et 老格式不支持原地修改，会提示另存为 xlsx。

4. 查找替换

  1. 点「查找替换」；
  2. 填「查找内容」「替换为」（留空 = 删除），可选「区分大小写」；
  3. 点「预演」→ 列表显示每条"旧值 → 新值 + 坐标"；
  4. 勾选要改的条目 → 替换选中项（同文件一次备份、一次写盘）。

四、字段映射页：把别的表转成台账

1. 登记模板（模板可替换）

  1. 点右上「登记模板」→ 选择任意 .xlsx（台账、统计表都行）；
  2. 系统自动解析多级表头，得到目标字段列表；数据起始行不对时可在模板卡片上调整；
  3. 同一个模板只需登记一次，之后一直可用。

2. 选来源与模板

  • 来源文件/工作表：要被转换的表；
  • 目标模板：登记过的模板（可切换，换成别的模板也能映射）。

3. 自动推荐

点「自动推荐」：按字段名、别名词典、类型、相似度给出"来源字段 → 目标字段 + 置信度"，点「全部应用为规则」可一键生成，再手工微调。

4. 映射矩阵（核心）

每一行一条规则，四个选择器 + 两个模式：

项 可选 含义
源行 fixed 固定行 / record 当前记录行+偏移 取哪一行（record 表示随每条记录下移）
源列 fixed / header 按字段名 / span 连续 N 列 取哪一列
目标行 同上 写到模板哪一行
目标列 同上 写到模板哪一列
模式 cell 逐格 / block 区域块 / transpose 行→列转置 / filldown 合并填充 / repeat 常量重复 怎么搬运
转换 identity 原样 / number 数值 / date 日期 / concat 拼接 / constant 常量 值的加工方式

"A 表某行 → B 表某列"怎么做：点「+ 区域转置（行→列）」，源行填固定行号（如 3）、源列选 span 起始 2 数量 6，目标行选 span 起始 2 数量 6、目标列填固定列（如 6），模式自动为 transpose —— 即把 A 表第 3 行 B~G 横排的 6 个值，竖排写入目标表 F 列。

5. 预演与保存

  • 点「预演（逐单元格）」：列出每一格的来源坐标 → 目标坐标 → 值，核对无误再生成；
  • 点「保存方案」，填方案名：以后同类表可直接读取方案（按来源表头指纹还会给出"匹配方案"提示）。

五、模板转换页：生成新表

  1. 选来源文件（自动列工作表）、映射方案、目标模板；
  2. 可改输出文件名（留空自动按"模板名_时间.xlsx"命名）；
  3. 点 开始转换：显示进度（读取来源 → 计算映射 → 注入模板 → 自检）；
  4. 成功后点 下载文件，或 打开所在文件夹 去 data/output/ 取；
  5. 生成物保留模板的原样式、合并单元格、列宽、公式；生成后会自动重新解析自检，失败不会产出坏文件。

转换不会修改来源表和模板原件。

六、数据对比页：核对两个版本

  1. 左侧选基准表、右侧选对照表（可以是不同文件、不同工作表）；
  2. 指定主键列：填 1 基列号（如 AF 或 32；多列用逗号/空格分隔，如 32,33），或直接勾选下方"从表头识别的主键候选"；
  3. 对比选项：
  • 忽略文本首尾空白（trim）——建议开；
  • 合并单元格/空值向下填充（filldown）——台账里项目名只写首行时建议开；
  • 数值容差——如 0.001，避免浮点误差误报。
  1. 点 开始对比：
  • 汇总卡片：匹配 / 新增 / 删除 / 修改（修改按行计）；
  • 差异表：类型、主键、字段名、左值 + 左文件/行/列/A1、右值 + 右文件/行/列/A1；
  • added = 仅右表有；removed = 仅左表有；changed = 两边都有但值不同；
  • 主键为空/重复会以告警列出，不会静默错配。
  1. 点 导出对比报告 下载 xlsx（修改黄、仅左红、仅右绿）。

七、设置页：工作区、文件、审计

区块 用途
工作区 改目录（可 浏览… 选文件夹）、切换工作区、重建索引（带进度条）、文件数/工作表数/单元格数/索引状态
文件清单 每个文件的格式、大小、状态（正常/错误/跳过）、错误原因；可按文件名/格式筛选
修改审计 每次写回的时间、文件、坐标、旧值、新值、结果；据此可定位问题
上方「刷新」 重新读取状态/文件/审计

需要整体回滚某次误操作时：到 data/backup/时间戳/ 找到对应文件副本，覆盖回去即可（审计记录里有备份路径）。

八、三个典型工作流

场景 1：找一份合同号并当场改掉备注

检索页搜 DEMO-JQSC-QT → 看结果定位到 第4行 AF4 → 点「编辑」→ 改「备注/新值」→ 保存并写回 → 设置页确认审计记录。

场景 2：把工单明细转成项目台账

字段映射页：登记台账模板 → 选工单表和台账模板 → 自动推荐 → 矩阵里把"工单编号→合同编码""扣分原因→备注"等规则调好（需要横排转竖排时用「区域转置」）→ 预演确认 → 保存方案 → 模板转换页选该方案生成。

场景 3：核对两版台账的差异

数据对比页：左右各选一份台账 → 主键填 AF（合同编码列）→ 勾选 trim/filldown → 开始对比 → 看差异表左右坐标 → 导出报告发人。

十、常见问题（FAQ）

Q1：点「打开所在文件夹」弹出 explorer.exe 应用程序错误（0xc0000142）？新版已修复（改用系统 ShellExecute 打开）。如果仍出现，请升级到最新 表格工具.exe；也可以直接「复制路径」粘到资源管理器地址栏。

Q2：想选文件夹却没有输入框可选？顶栏和设置页都有 浏览… 按钮，会弹出 Windows 原生"选择文件夹"对话框，选完自动填入并切换工作区。

Q3：搜索很慢 / 提示未索引？首次搜索或重建索引需要 20 秒左右（取决于文件数量）。只会在启动后第一次建索引，之后都是毫秒级。文件增删后点「重建索引」。

Q4：提示"文件已被外部修改，请刷新后重试"？该文件在索引之后被 WPS/Excel 改过。刷新页面重新搜索，再改一次即可（也可以先关闭占用它的 WPS 窗口）。

Q5：为什么 .xls 文件不能改？.xls/.et 是老二进制格式，回写风险高，本工具只读不写。用 WPS/Excel 另存为 .xlsx 后再编辑。

Q6：为什么按钮点了没反应？确认「表格工具」窗口还开着（服务在运行）；浏览器地址应是 http://127.0.0.1:8765/。若端口被占用，启动器会提示。

Q7：杀毒软件报风险？启动器会拉起同目录的 runtime\python.exe，属正常行为；把整个程序目录加入信任区即可。

Q8：换电脑怎么办？整个 表格工具 目录拷走即可（自带 Python 运行时）；data/ 里是方案、备份、审计，一起拷走更完整。

Q9：索引里为什么有"错误/跳过"的文件？加密文件、超大文件（>80 MB）、损坏文件会被跳过，设置页的「文件清单」里有具体原因。

十一、支持格式与限制

项 说明
可读 .xlsx .xlsm .xlsb .xls .csv .et（按文件真实格式识别，不看扩展名）
可写回 .xlsx .xlsm .et（zip 型）；.xls/OLE 型 .et 只读

单文件 > 80 MB 或加密文件跳过
平台 Windows 10/11（64 位），监听 127.0.0.1:8765，不对外网开放

十二、小技巧

  • 搜索框回车即搜；多关键词用空格，短语用英文双引号；
  • 深链分享：地址栏 #search?q=合同 直接把这次查询发给同事；
  • 结果表「复制路径」可粘贴到任何地方；
  • 转换/对比的生成物都在 data/output/，文件多时按时间排序取最新；
  • 映射方案保存后，同类表会提示"匹配方案"，省得重配。
